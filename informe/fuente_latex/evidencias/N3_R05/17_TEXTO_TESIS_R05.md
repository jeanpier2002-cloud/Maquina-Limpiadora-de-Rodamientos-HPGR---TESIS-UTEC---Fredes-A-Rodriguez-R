# Texto propuesto para la tesis — iteración R05

La revisión R05 mantuvo la configuración global N3 con perfil W6×9 como base de desarrollo y corrigió cinco hallazgos de integración mecánica. En primer lugar, se distinguió el error físico de colocación del rodamiento de la envolvente del centro de gravedad del conjunto móvil. Se adoptó como requisito propuesto una desviación radial máxima de 5 mm, frente a un límite geométrico conservador de contacto pleno de 22 mm. La excentricidad inercial equivalente, 7.875 mm para una aceleración de 0.3 m/s², se empleó para redistribuir las reacciones y no para desplazar la geometría del rodamiento.

Los centradores se desarrollaron como cassettes completos con estados activo y retraído, mientras que la retención quedó a cargo de tres topes bajos conectados estructuralmente. El manillar de empuje se integró al travesaño extremo mediante postes y placas. Estas piezas fueron predimensionadas, pero sus materiales, uniones, protección y funcionamiento deben cerrarse mediante especificaciones y ensayos.

El cálculo de ruedas consideró las ternas físicamente admisibles y obtuvo una demanda de selección de 21.865 kN por rueda. La combinación SPKVS 200K + riel A45 permanece como candidata. Para los apoyos de riel se recorrió la mesa entre carga y lavado; la demanda vertical de instalación resultó 26.741 kN, por lo que se descartó el reparto P/2 como base de dimensionamiento.

La conclusión se clasifica como `SELECCION_COMPARATIVA_PRELIMINAR_DEL_MODELO_GLOBAL`. No constituye liberación de fabricación: quedan pendientes la simulación SAP R05, la instalación real del riel, las uniones, la trayectoria completa de Head A y los ensayos de centrado, rodadura, empuje, frenado y bloqueo.
